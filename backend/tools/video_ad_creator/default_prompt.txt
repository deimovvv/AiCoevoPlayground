━━━ FRAME-TO-FRAME RULES ━━━

Each frame will be animated INTO the next using AI video. For smooth transitions:

- Consecutive frames share the SAME environment and lighting
- Camera moves GRADUALLY between frames (no jumps from close-up to wide in one cut)
- The product/character position shifts naturally — don't teleport them
- Color palette stays consistent throughout
- Think: keyframes from a single continuous shot, not separate photos

CONSISTENCY (CRITICAL):
- Same character in every frame (identical face, body, skin, hair)
- Same wardrobe in every frame (identical color, fit, texture)
- Same product appearance in every frame
- Same lighting direction and color temperature
- Same visual style across every frame
